Assignment: AI-Based Timetable Scheduler
Course: Artificial Intelligence | Class: B.Tech, Second Year Team size: 3 students | Duration: 2 weeks |
Total marks: 18(+12 bonus) Submission: GitHub link, report (PDF), demo.
1. Problem Statement
Every college has to prepare a timetable that places lectures and labs into rooms and time slots without clashes.
Build an application that automatically generates a valid timetable using the AI search techniques taught in class,
and then compare those techniques on real data.
2. Learning Objectives
After this assignment you should be able to:
1. Model a real problem as a Constraint Satisfaction Problem (CSP) with variables, domains and
constraints.
2. Implement backtracking search with heuristics (MRV, forward checking, and others).
3. Implement a local search method (Min-Conflicts) and explain how it differs from systematic search.
4. Separate hard constraints from soft constraints and design a cost function.
5. Wrap an AI algorithm inside a usable application.
6. Evaluate and compare algorithms using experiments, and report the results honestly.

4. Constraints
4.1 Hard constraints (must never be violated)

H1. A teacher cannot teach two sessions at the same time.
H2. A class cannot have two sessions at the same time.
H3. A room cannot be used for two sessions at the same time.
H4. Room capacity must be at least the class strength.
H5. Lab sessions must be in lab rooms; theory sessions in classrooms.
H6. A teacher can only be scheduled in their available slots.
H7. Every subject gets exactly its required weekly hours.
H8. A teacher's load should not exceed their maximum weekly load.
H9. Each class must have its lunch break in its assigned time slot, with no session scheduled then.

5. Technical Requirements
5.1 Problem formulation (starting hint)
•
•

Variable: one lecture session, for example (Class A, Maths, session 2).
Domain: possible (day, period, room) combinations. You may fix the teacher in advance (subject-teacher
mapping) to keep the domain small.
Constraints: binary constraints between variables that share a teacher, class or room, plus unary
constraints (room type, capacity, availability).
Cost function for local search: Cost = 1000 x (hard violations) + (soft penalties)

5.2 Mandatory algorithms
Algorithm 1: Backtracking CSP
•
•
•

Implement plain backtracking first (this is your baseline).
Then add at least three improvements from this list: MRV, Degree heuristic, Least Constraining Value,
Forward checking, AC-3 (as preprocessing).
Recommended minimum: MRV + Forward checking + Degree heuristic.

Algorithm 2: Min-Conflicts local search
•
•
•
•

Start from a complete (possibly conflicting) assignment.
At each step, pick a conflicted variable and move it to the value that minimizes conflicts.
You must define and justify: the initial assignment, how the conflicted variable is chosen, tie-breaking, and
the iteration limit.
Include a method to escape plateaus (random walk with a small probability or random restarts).

5.3 Optional algorithms (+12 bonus marks)

•

Simulated Annealing: define neighbourhood moves (swap two sessions, move a session to a free slot),
initial temperature, cooling schedule and stopping rule.
Hybrid: use Backtracking to get a feasible timetable, then improve soft-constraint quality with Simulated
Annealing.
Hill Climbing: may be included as an extra comparison point.
